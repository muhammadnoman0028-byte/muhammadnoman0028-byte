### 🚀 Featured projects

#### 📄 [document-toolbox](https://github.com/muhammadnoman0028-byte/document-toolbox)
A browser-based document & file utility suite with a neomorphic UI and an Android build via Capacitor.
DOCX ⇄ PDF, image compression, PDF/DOCX optimisation — processed **client-side** so files stay on your device.
`JavaScript` · `Capacitor` · `pdf-lib` · `pdf.js` · `JSZip`

#### 📝 [docx-to-pdf](https://github.com/muhammadnoman0028-byte/docx-to-pdf)
A focused DOCX-to-PDF conversion tool/project — simple, fast, and easy to use.
`Documents` · `Conversion`

#### 🎬 [youtube-bulk-downloader](https://github.com/muhammadnoman0028-byte/youtube-bulk-downloader)
Bulk-download an entire YouTube channel to merged MP4s, thumbnails, and metadata with a live WebSocket dashboard.
Fully **resumable**: interrupt at video 34 of 200 and it continues from 34.
`Python` · `FastAPI` · `yt-dlp` · `FFmpeg` · `WebSockets`

#### 📅 [youtube-auto-uploader](https://github.com/muhammadnoman0028-byte/youtube-auto-uploader)
Turns a folder of finished videos into a hands-off daily publishing schedule.
Bulk planning, one upload per day, private uploads with `publishAt`, copyright guarding, and Windows Task Scheduler integration.
`Python` · `YouTube Data API v3` · `OAuth 2.0` · `FastAPI`
