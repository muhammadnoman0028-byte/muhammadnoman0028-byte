### 🚀 Featured projects

#### 📄 [Docx.Hub](https://github.com/muhammadnoman0028-byte/Docx.Hub)
A browser-based conversion and compression hub with a neomorphic UI and Android build via Capacitor.
DOCX ⇄ PDF, image compression, PDF optimising — all processed **client-side**.
`JavaScript` · `Capacitor` · `pdf-lib` · `pdf.js` · `JSZip`

#### 🎬 [YouTube Channel Bulk Downloader](https://github.com/muhammadnoman0028-byte/youtube-downloader)
Bulk-download an entire channel to merged MP4s, thumbnails, and metadata — with a live WebSocket dashboard.
Fully **resumable**: interrupt at video 34 of 200 and it continues from 34.
`Python` · `FastAPI` · `yt-dlp` · `FFmpeg` · `WebSockets`

#### 📅 [YouTube Auto Uploader](https://github.com/muhammadnoman0028-byte/yt-auto-uploader)
Turns a folder of finished videos into a hands-off daily publishing schedule.
Bulk planning, one upload per day, private uploads with `publishAt`, copyright guarding, and Windows Task Scheduler integration.
`Python` · `YouTube Data API v3` · `OAuth 2.0` · `FastAPI`

  credentials and personal configuration stay mine.
